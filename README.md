# My_Car · STM32 红外遥控 + 超声波避障智能车

> 基于 STM32F103C8T6 的双轮差速小车：红外遥控行驶，超声波配合舵机扫视判断左右空间，自主绕开障碍。
>
> 标准外设库裸机实现，Keil MDK 工程，无 RTOS、无第三方库依赖。

## 项目概述

这是一辆能在两种模式下工作的小车：

- **遥控模式**：红外遥控器控制前进、后退、左转、右转、停止，速度分五档（20 / 40 / 60 / 80 / 100）。
- **避障模式**：按下功能键后小车自行前进，遇到障碍停下、转动舵机测量左右两侧距离，选择空间更大的一侧转向，然后继续直行。

主控只用了一颗 STM32F103C8T6（72 MHz，64 KB Flash / 20 KB RAM），外设全部走片上资源：两个定时器分别输出电机 PWM 和舵机 PWM，一个定时器做超声波回波计时，还有一个定时器做红外输入捕获。整个工程没有用到任何中断服务以外的并发机制，主循环是单线程轮询。

选择这个方案的原因是成本与可调试性：单超声波 + 舵机的组合比三路超声波便宜，也比纯碰撞开关式的随机转向更“聪明”——它能判断哪边更空，而不是撞了才退。

## 软件结构

工程按职责分层，改某一层不影响其他层：

| 目录 | 职责 | 主要内容 |

驱动层统一暴露 `XXX_Init()` 与 `XXX_操作()` 两类接口，应用层只依赖接口，不直接碰寄存器。

## 核心实现

### 电机控制

`Motor_SetLeftSpeed()` / `Motor_SetRightSpeed()` 接收带符号的 `int8_t`：正数前进、负数后退、零为刹车。函数内部把符号翻译成方向引脚电平，把绝对值写进 PWM 比较寄存器。

四个组合动作由此推出：

```c
void Self_Left(uint8_t Speed){          // 原地左转
    Motor_SetLeftSpeed(Speed);
    Motor_SetRightSpeed(-Speed);
}
void Turn_Left(uint8_t Speed){          // 单侧驱动转弯
    Motor_SetLeftSpeed(Speed);
    Motor_SetRightSpeed(0);
}
```

### 超声波测距

`HCSR04_GetValue()` 的做法是：拉高 TRIG 20 μs 触发，等待 ECHO 变高后启动 TIM1（预分频 72-1，计数频率 1 MHz，即 1 个计数 = 1 μs），ECHO 回落后停表读计数，再换算距离：

```c
distance = (Cnt * 1.0 / 10 * 0.34) / 2;   // 单位 cm
```

`Cnt / 10` 得到 10 μs 的倍数，声速 0.34 cm/μs，除以 2 是因为声波走了来回。周期寄存器设 60000-1，对应 60 ms 溢出，覆盖约 10 米的量程，实际有效范围按 2–400 cm 处理。

函数末尾有 `Delay_ms(100)`。这是 HC-SR04 的测量间隔要求，连续触发会读到上一次的残值。

### 避障决策

`BiZhang_Init()` 是一段顺序执行的决策流程，没有状态机嵌套：

1. 前测。距离大于阈值（20 cm）→ 直行，本轮结束。
2. 小于阈值 → 停车，舵机转到 0°（右侧），停 320 ms 等舵机到位，再测一次。
3. 右侧通畅 → 舵机回中，原地**右转** 500 ms，然后直行。
4. 右侧也堵 → 舵机转到 180°（左侧）测一次，通畅则回中、原地**左转** 500 ms 后直行。
5. 两侧都不通 → 停车等待，不再动作。

转向时长 500 ms 是实车调出来的经验值，与地面摩擦、电池电压都有关系，换车或换地面需要重调。阈值 20 cm 同理，是“能刹住”与“不误触发”之间的折中。

### 红外解码

`Remote_Init()` 把 PB9 配成上拉输入，用 TIM4 通道 4 做上升沿捕获，预分频后计数频率 1 MHz。`TIM4_IRQHandler()` 里按 NEC 协议的时序判定：9 ms 低电平 + 4.5 ms 高电平为帧头，随后 32 位数据按“高电平长度”区分 0 与 1，最后用 `RmtSta` 的位域记录收码状态与连发计数。

`Remote_Scan()` 返回映射后的键值，`main.c` 用 `switch` 把它翻译成动作：

| 键值 | 动作 |
| --- | --- |
| 24 / 74 / 16 / 90 | 前进 / 后退 / 左转 / 右转 |
| 56 | 停止 |
| 104 / 176 | 加速 / 减速（步进 20） |
| 98 / 162 | 进入避障模式 / 退回遥控模式 |

键值是遥控器实测得到的编码，不同遥控器不一样，换遥控器需要重新标定。

## 编译与烧录

1. Keil MDK 打开根目录的 `Project.uvprojx`，器件已配置为 STM32F103C8。
2. 确认 ARM Compiler 5（AC5）可用——该工程基于标准外设库，未适配 AC6。
3. `Rebuild`，无错误后接 ST-Link 或 J-Link，`Download` 烧录。
4. 上电后 LED 均熄灭；按遥控器方向键，遥控指示 LED 会短暂闪烁，说明收码与解码正常。

## 已知限制与后续方向

这几条是实车跑下来暴露的问题，也是下一步要改的地方：

- **两侧共用一路 PWM 占空比**：当前只能做“同速直行”与“原地转”，无法做内外轮差速的弧线转弯，也跑不了闭环调速。要改需要拆出第二路 PWM 通道，或换用带独立使能的驱动芯片。
- **测距是阻塞的**：`while` 等 ECHO 期间 MCU 什么都不能做，超时保护靠定时器溢出兜底。改成输入捕获 + 中断能把这段等待释放出来。
- **避障无记忆**：每次决策只看当前帧，不会记录“上次选了哪边”，在凹形障碍前可能来回摆动。
- **没有闭环**：电机是开环给定占空比，电池电压下降后实际转速会漂。加编码器 + PID 是自然的下一步，之后再考虑用 FreeRTOS 把感知、决策、执行拆成独立任务。
